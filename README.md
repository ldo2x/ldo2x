# عبدالرحمن

طالب في جامعة الملك عبدالعزيز، وأحب أبرمج ألعاب وأدوات أستخدمها أنا وربعي.
هنا أحط المشاريع اللي اشتغلت عليها.

## المشاريع

### [منصة دحوم](https://github.com/ldo2x/dahoom)
ألعاب جماعية نلعبها في الجلسات: الشاشة على التلفزيون، وكل فريق يلعب من جواله.
فيها ألف نقطة، وهوامير، وخلية الحروف، وارسم وخمّن.
مسويها بجافاسكربت بدون أي إطار.

[جربها من هنا](https://ldo2x.github.io/dahoom/)

### [2X Ping](https://github.com/ldo2x/2XPing)
برنامج ويندوز لديدلوك: يقيس البنق لكل منطقة ويثبّت البحث على المناطق اللي تختارها.
مكتوب بسي شارب، ومفتوح المصدر.

[صفحة البرنامج](https://ldo2x.github.io/2XPing/)
