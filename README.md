# عبدالرحمن

طالب في جامعة الملك عبدالعزيز، أبرمج ألعاب وأدوات.

## مشاريعي

| المشروع | وش هو |
|---|---|
| **[منصة دحوم](https://ldo2x.github.io/dahoom/)** | ألعاب جماعية للجلسات، الشاشة على التلفزيون والتحكم من الجوال: ألف نقطة، خلية الحروف، هوامير، ما أصدقك، ارسم وخمّن |
| **[لقطة](https://ldo2x.github.io/laqta/)** | مسجّل لقطات الألعاب لويندوز: زر يحفظ آخر الدقائق، كل صوت في مسار، تعديل ومشاركة لديسكورد |
| **[2X Ping](https://ldo2x.github.io/2XPing/)** | برنامج ويندوز يقيس بنقك في ديدلوك ويثبّت البحث على المنطقة اللي تختارها |
